# Agentic Stock Researcher

[English](README.md) · 简体中文

按对冲基金的投研流程搭建，从选股到建仓五段闭环，财报直连 SEC 官方数据，拒绝幻觉，不预测涨跌，只分析股票价值。

作为单个 SKILL.md 包交付，不绑定 Claude Code，也不是托管服务。装进任何支持 SKILL.md 的 AI 工具，配置你自己的市场和数据源，自己跑。

## 一次真实运行

英伟达，2026 年 8 月 19 日。财报取自 SEC EDGAR，行情取自 Yahoo，除了一个联系邮箱
没有配置任何东西。

```
FY2026 10-K，报告期截至 2026-01-25
  净利润                 $120.067B    us-gaap:NetIncomeLoss
  折旧摊销                 $2.843B    us-gaap:DepreciationDepletionAndAmortization
  资本开支                 $6.042B    us-gaap:PaymentsToAcquireProductiveAssets
  股本                     242.0 亿    us-gaap:EntityCommonStockSharesOutstanding

  股东盈余               $116.868B    每股 $4.83
  股价                     $219.87    实时价，16:23 UTC

反向 DCF                     27.4%    当前价格已经隐含的年复合增速
                                      折现率 9.2%*，永续增长 3%
```

这次取数拒绝了两个标签，日志里写明了。一个 **2012 年**的资本开支，一个 **2021 年**的
折旧摊销，都挂在英伟达早就不再使用的标签下。取任何一个，都会得到一个看起来很正常的
十几年前的数字。这就是下面那张表里英伟达那一行，发生在产出这张表的同一次运行里。

接下来是你自己给的情景。这三个增长率是假设，不是产出。

```
            增长率      每股价值      永续价值占比
  乐观        30%       $243.04          65%
  中性        20%       $165.46          62%
  悲观        10%       $110.83          59%

  概率加权价值            $171.20
  当前股价                $219.87
  半 Kelly                  0.00%     期望收益 -22.1%
```

从这组数字里能读出三件事。

**先看反向 DCF 那一行。** 它把「英伟达贵不贵」换成一个你自己能回答的问题。这家公司
未来十年能不能每年把股东盈余复合 27.4%。这是你能判断的事，目标价不是。

**永续价值占比 62% 是一个警示标签。** 上面每一档估值里，将近三分之二的价值来自永续
假设，而不是被建模的那十年。这说的是折现率，和说英伟达一样多，你该在相信这个数字
之前先看到它。

**半 Kelly 在全世界最热门的股票上给了零。** 即使中性档给 20%、乐观档给 30%，概率
加权价值仍然落在股价下方，期望收益为负，算式拒绝下注。它不是答不出来，它就是在回答。

\* 折现率没有默认值。必须带来源提供，来源会存进记录，所以这次估值日后可以复核。

## 为什么用这个

LLM 选股工具会坏在四个地方。这四条都躺在同类项目的 issue 列表里，每一条这里都有
对应的做法。

**同一次运行里，不同地方报出的财务数字对不上。** 一个 agent 算的资产负债率和另一个
不一样，同一家公司，同一次运行。这里一个数字只取一次，声明成带来源、单位、数据时点的
`Fact`，喂给同一个计算的数字共用一个 `group`，所以季度分子除以 TTM 分母会被拦下来，
不会被平均掉。

**同样的输入重跑一次，答案变了。** 同一个代码、同一天、同一个模型，评级不一样。
这里不让模型做算术。DCF、反向 DCF、Kelly 求解全是确定性的 `Decimal` 代码，每条记录
追加进 SQLite 而不是覆盖，所以两次运行可以对账，答案变了能指出是哪一项变的。

**配置本身就是一个项目。** conda 环境、数据商的 key、模型的 key、照着 wiki 填的
`.env`。这里零 pip 依赖，Python 3.10 加标准库就够。行情和 A 股财报不需要任何 key，
美股财报只需要一个联系邮箱，因为 SEC 要求申请方留下联系方式。

**数据错得看起来完全正常。** 这一条没人去查，而大部分工作量花在这儿。直接读 XBRL 和
免费接口会拿到一批通得过任何直觉检查、实际是错的数字。下面每一条都是实盘撞到的，
现在都有规则拦着。

| 公司 | 直接读的结果 | 实际 | 原因 |
| --- | --- | --- | --- |
| Simon Property | 13.0 亿股 | 3.24 亿股 | 加权平均股本按期间条目申报，四个季度被加了起来 |
| 麦当劳 | 716 股 | 7.08 亿股 | 这项数据以「百万」为单位申报 |
| 星巴克 | 折旧摊销 $362M | $1.77B | 一个更新的单季数据压过年度数据，公司随即显示为没有股东盈余 |
| 壳牌（伦敦） | $3,356 | 约 $45 | 伦敦报价单位是便士，却被标成了美元 |
| 英伟达 | 资本开支停在 2020 年 | 当期 | 2020 年前用的旧标签一直压过现在在用的那个 |
| 贵州茅台 | 折旧摊销 3.66 亿 | 41.5 亿 | 折旧拆在六个字段里，各家申报的子集还不一样 |

四个季度加出来的股本，仍然是个合理的股本。一个季度的折旧，仍然是个合理的折旧。
没有一条通不过直觉检查，所以每一条都要一条规则加一条回归测试，光给警告不够。

## 它拒绝做什么

拒绝是功能的一部分。下面每一种情况，硬算都会给出一个看起来很确定、实际没有意义的数字。

- **银行、保险和多数 REIT。** 股东盈余等于净利润加折旧减资本开支，而它们常常没有
  资本开支这一行。缺失项被当成零，恰好把最吃资本的那类生意美化了。
- **亏损公司。** 算出来是负的目标价，配一个看起来很正常的永续占比，那是两个负数相除。
- **同一家公司混着两种货币。** 人民币股价配美元财报，差一个汇率，而每一位数字看着都对。
- **以货币辅币报价的标的。** 伦敦按便士报价，币种标签是对的，只有单位错了，
  所以没有任何下游检查看得见。
- **没有边际的仓位。** 期望收益在当前价格下不为正时，Kelly 给 0。这是算式在拒绝下注。

## 详细功能

一个 skill，五个阶段。每一段交给下一段的是一份经过校验的结构化记录而不是一段文字，所以从量化筛子来的标的和从宏观判断反推来的标的，用的是同一把尺子。

| 阶段 | 做什么 | 产出 |
| --- | --- | --- |
| 发现 | 自定义条件筛选，也支持从一个观点反推能够表达的股票 | `Candidate` |
| 研究 | 对股票生成完整研究报告，AI 对话辅助用户建立投资观点 | `Thesis` |
| 估值 | 生成 DCF 估值模型，包含交互式 HTML 文件，支持实时拖动增长率、折现率 | `Valuation`、`Verdict` |
| 仓位 | 使用半 Kelly 计算公式，帮助用户决策仓位数量，控制回撤 | `Portfolio` |
| 复查 | 卖出前调出建仓观点，减少价格波动引起的情绪化交易，增强决策质量 | `Sellcheck` |

`skills/agentic-stock-researcher/` 是自包含的：SKILL.md 负责路由，每个阶段一份指南，Python 库就放在旁边。把这一个目录复制到你的 AI 工具里就能用。

## 设计原则

- **数字来自工具，不来自模型。** 任何要进入输出的数字，都要先过 `airesearch/factcontract/` 的 Fact 契约：数据陈旧、同一家公司的金额混着两种货币，
  这两种直接硬停；单位或量级异常给警告。非美元本身不拒绝，人民币股价配人民币财报照常估值。
- **不预装任何立场。** 没有内置的筛选清单，没有预设的红线，没有强制的投委会。筛选标准由你自己定义并保存；在你定义之前，intake 就是一次通用的开放搜索。
- **纯标准库。** 没有任何 pip 依赖，有 Python 3.10+ 的地方就能跑。

## 安装

让你的 AI 工具指向 `skills/agentic-stock-researcher/`，或者克隆后原地安装：

```bash
git clone https://github.com/Rever3I/agentic-stock-researcher.git
cd agentic-stock-researcher
pip install -e .
```

skill 目录自带库，单独复制它就够用。如果你的 AI 工具不会把 skill 目录加进 `sys.path`，SKILL.md 里给了那一行代码。

然后跑一次引导。它会建出配置文件、打印路径、从每个能应答的数据源真的取一次数，并对
缺的项打印出确切的键和文件。

```python
from airesearch.setup_guide import guide
print(guide())
```

行情和 A 股财报零配置直接应答。美股财报需要一个联系邮箱，因为 SEC 强制要求。改完配置
再跑一次——填错的 key 和填对的长得一样，取到数才分得出来。

记录写入 `db/research.db`，首次写入时自动创建。想换位置就设 `AI_RESEARCH_DB` 环境变量。

## 配置

`config/research-profile.json` 出厂内容如下（**默认是 `en`，想要中文研报就把它改成 `zh-CN`**）：

```json
{
  "output_language": "en",
  "sizing_method": "half_kelly",
  "fixed_pct": 0.05,
  "debate_enabled": false,
  "sec_contact": "",
  "fred_api_key": "",
  "position_cap": 1.0
}
```

- `output_language` —— **研究成果用什么语言写**（thesis 正文、估值说明、结论）。填 `zh-CN` 就出中文研报，不需要另一套代码。语言标签不设白名单。注意这不影响程序自身的日志和报错，那些保持英文，方便任何人搜索排查。
- `sizing_method` —— 仓位算法：`half_kelly` / `full_kelly` / `fixed_pct` / `custom`
- `fixed_pct` —— `sizing_method` 选 `fixed_pct` 时使用的固定仓位（占总资金的比例）；`custom` 则由调用方直接给出权重
- `debate_enabled` —— 是否启用可选的分歧辩论层
- `sec_contact` —— 姓名加邮箱，例如 `"Jane Roe jane@example.com"`。SEC 要求 User-Agent 里带联系方式，不填会返回 403，美股财报就没有数据源
- `fred_api_key` —— [FRED](https://fredaccount.stlouisfed.org/apikeys) 的免费密钥，用于给折现率提供有出处的无风险利率
- `position_cap` —— 集中度上限（占总资金的比例），在算完仓位后套用。Kelly 不知道组合里还有什么，这一层判断放在这里；`1.0` 表示不设上限

用 JSON 而不是 YAML：本项目零第三方依赖，而标准库没有 YAML 解析器。

`ensure_profile()` 会在第一次调用时按默认值把这个文件建出来并返回路径；读设置之前
先调它，并且报它给的那个路径。路径取决于安装方式——源码仓库里是
`config/research-profile.json`，作为独立 skill 安装时是
`~/.agentic-stock-researcher/research-profile.json`——写到另一个位置的设置永远不会被读。

想用另一份配置就设 `AI_RESEARCH_PROFILE` 环境变量指向它。所有配置项都有可用的默认值，配置文件缺失、只写一部分、甚至存坏了，都会退回默认值并给出警告，不会中断流水线。

## 当前进度

五个阶段全部建成，连同它们共用的底座：记录契约、带外键约束的 SQLite 存储、Fact 契约、基于 Decimal 的股东盈余 DCF（含反向 DCF 与多情景），以及能处理多结果分布（而不只是二元情形）的 Kelly 仓位求解器。

## 数据源

适配器返回的是 `Fact` 对象而不是裸数字，所以一个数值不可能在缺少来源、单位、时点的情况下进入估值。每个 domain 是一条链：主源失败就试下一个，并把降级过程记进日志——因为一个悄悄一直失败的主源，看起来和正常工作的一模一样。

| Domain | 数据源 | 需要什么 |
| --- | --- | --- |
| `price` | Yahoo（两个 host）→ 腾讯自选股 → Stooq | 无 |
| `us_equity` | SEC EDGAR XBRL 财报数据 | `sec_contact` |
| `macro` | FRED | `fred_api_key`（免费） |
| `cn_equity` | 东方财富公开接口，再退到 Wind | 无 |

```python
from airesearch.data.adapters import configure, fetch, status_report

print(status_report(configure()))     # 哪些接好了、哪些能跑
facts = fetch("us_equity", "KO")      # 净利润、折旧摊销、资本开支、股本
```

行情源零配置即可用，这是刚克隆下来时最要紧的情形，而且有两条互相独立的免费通路：
Yahoo 和腾讯自选股，后者在东方财富行情接口连续 502 的那几个小时里一直是通的。
A 股同样零配置：`cn_equity` 主源是
东方财富的公开接口，和 Yahoo 行情一样属于非官方、无文档的那一类，所以解析失败时会明确
报错而不是返回一个看起来合理的数字。Wind 留在它后面作为可选主源，按 Wind 官方文档接口
写成，但**未经真实终端验证**——WindPy 随付费产品分发，无法另行安装。

筛选条件可以存下来复用：`airesearch.data.screen_store` 管理具名 profile，套用之后候选记录会带上 `screened=True` 和 profile 名。没有存过任何条件时，发现阶段跑的是通用开放搜索——这仍然是默认行为，不是缺省状态。
