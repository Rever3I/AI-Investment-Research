# 一人投资交易投研团队 Pro 版

按对冲基金的投研流程搭建，从选股到建仓五段闭环，财报直连 SEC 官方数据，
拒绝幻觉，不预测涨跌，只分析股票价值。

一家基金把这五件事分给五个人做：筛选、研究、估值、定仓位、卖出前复查。
这套 skill 把五个岗位的流程写进同一条流水线，每一段交给下一段的是一份带来源、
带时点的结构化记录，所以从量化筛子来的票和从一个宏观判断反推来的票，
用的是同一把尺子。

---

## 发现

**自定义条件筛选，也支持从一个观点反推能够表达的股票。**

两条入口。一条是你给条件，它给名单，每个附一句入选理由。另一条是你先有判断——
「电网改造的开支这几年下不来」——它顺着这条逻辑推到产业链上真正能表达它的公司。

第二条入口是大多数人真正的起点：想法先有，标的后有，中间那一步通常靠翻帖子。

## 研究

**对股票生成完整研究报告，AI 对话辅助用户建立投资观点。**

报告包含生意怎么赚钱、管理层、竞争格局、市场空间，以及 8-12 条风险，
每条风险后面跟着「什么情况下这个判断就是错的」。

这一段不替你下结论。它把材料铺开、把反面证据摆出来、追问你没想清楚的地方，
结论留给你写——因为第五段要拿这份结论跟未来的事实对账，署名必须是你。

## 估值

**生成 DCF 估值模型，包含交互式 HTML 文件，支持实时拖动增长率、折现率。**

一次真实运行，可口可乐，数字全部实时取自 SEC EDGAR：

```
股东盈余      $12.0B      净利润 + 折旧摊销 - 资本开支，FY2025 10-K
股本          43.1 亿股   CommonStockSharesOutstanding
股价          $86.84      Yahoo 行情，已通过时效校验

反向 DCF      19.7%       当前价格已经隐含的年复合增速
                          折现率 9.2%，永续增长 2.6%

情景估值      乐观 $54.24   中性 $47.96   悲观 $40.61
半 Kelly      0.00%       这个价格上没有边际
```

先看反向 DCF 这一行。它把「可口可乐现在贵不贵」换成了一个你自己能回答的问题：
一家软饮公司，未来十年能不能每年把股东盈余复合 19.7%。后面的情景估值用的是你
自己填的增长率假设。

**交互式页面**：每次估值生成一个自包含的 HTML 文件。拖动折现率或永续增长率，
所有情景当场重算。没有 CDN、没有外部字体、没有任何网络请求，几年后在一台断网的
机器上打开照样能跑。

页面第一次打开显示的是保存下来的那组数字，并且标明这一点；你动过参数之后它会
标记为「已重算」。某个情景如果自带折现率，你调全局折现率时它不受影响——
悲观情景不会在你手底下悄悄变成中性情景。

页面还给出每个情景的永续价值占比。一个 85% 价值来自永续段的估值，
说的更多是折现率而不是这门生意，这件事应该看得见。

## 仓位

**使用半 Kelly 计算公式，帮助用户决策仓位数量，控制回撤。**

你给情景概率，它算权重。用的是多结果分布的 Kelly 解，不是教科书里那个二元公式，
所以「乐观/中性/悲观」三档、五档都能直接算。

半 Kelly 是默认值，也可以切成全 Kelly、固定比例，或者你自己给权重。
另外有一层集中度上限，在算完之后套用——Kelly 不知道你组合里还有什么，
这个判断留在外面。

当期望收益在当前价格下不为正，它给 0。这是算式在拒绝下注。

## 复查

**卖出前调出建仓观点，减少价格波动引起的情绪化交易，增强决策质量。**

它把当初那份 thesis 调出来，跟现在的事实对账，把变化分成三类：
事实变了、判断变了、依然成立。

这三种情况该做的事完全不同，但在一个正在浮盈 60% 的仓位里，它们的感觉是一样的。

## 数据源

SEC EDGAR XBRL（免费）+ Yahoo/Stooq 行情（零配置）+ FRED 宏观 + Wind（可选，需终端）。
返回数据自带来源，数据过期自动截停。

| 领域 | 数据源 | 需要什么 |
| --- | --- | --- |
| 行情 | Yahoo（两个 host），再退到 Stooq | 无 |
| 美股财报 | SEC EDGAR XBRL | 一个联系邮箱 |
| 宏观 | FRED | 免费 key |
| 中国上市公司 | Wind | 已授权的终端 |

每个领域是一条链。主源失败会自动试下一个，并把这次降级记进日志——
一个悄悄一直失败的主源，从外面看和正常工作的一模一样。

## 「拒绝幻觉」具体指什么

不是让模型少编，是让数字根本不经过模型。每个数字进入报告前都带着来源、单位和
数据时点，超过时效上限直接中断这次运行。

真正难的部分在这里：直接读 XBRL 会得到一批看起来完全正常、实际是错的数字。
下面是实盘跑真实申报文件时撞到的案例，每一条现在都有对应的规则拦着：

| 公司 | 直接读的结果 | 实际 | 原因 |
| --- | --- | --- | --- |
| Simon Property | 13.0 亿股 | 3.24 亿股 | 加权平均股本按期间条目申报，四个季度被加了起来 |
| 麦当劳 | 716 股 | 7.08 亿股 | 这项数据以「百万」为单位申报 |
| 星巴克 | 折旧摊销 $362M | $1.77B | 一个更新的单季数据压过了年度数据，公司随即显示为没有股东盈余 |
| 壳牌（伦敦） | $3,356 | 约 $45 | 伦敦报价单位是便士，却被标成了美元 |
| 英伟达 | 资本开支停在 2020 年 | 当期 | 公司 2020 年前用的旧标签一直压过现在在用的那个 |

这些数字没有一个通不过直觉检查。四个季度加出来的股本，仍然是个合理的股本；
一个季度的折旧，仍然是个合理的折旧。只能靠规则拦：存量指标永不求和、
期间按实际天数过滤、报价必须带币种、超过时效上限的数据直接拒绝。

## 它拒绝做什么

拒绝在这里是功能的一部分。下面每一种情况，硬算都会得到一个看起来很确定、
实际没有意义的数字。

- **银行和 REIT。** 它们常常没有资本开支这一行，而股东盈余 = 净利润 + 折旧摊销 -
  资本开支。缺失项会被当成零，恰好把重资本的那类生意美化了。它会直接说这个方法
  不适用。
- **亏损公司。** 对负的股东盈余做 DCF，会得到一个负的目标价，配一个看起来很正常的
  永续占比——那是两个负数相除的结果。
- **同一家公司混着两种货币。** 人民币股价配美元财报，算出来的估值会差一个汇率，
  而每一位数字看上去都很正常。它在这种组合出现时直接中断。非美元本身不拒绝——
  A 股用人民币股价配人民币财报是一次正确的估值，港股同理。
- **以货币辅币报价的标的。** 伦敦按便士报价，壳牌回来是 3356，实际约 45 英镑。
  这个数字连币种标签都是对的，只有单位错了，所以没有任何下游检查能看见它。
- **外国私人发行人。** 它们按 IFRS 申报，这套工具读不了，会明说这一点，
  而不是让你以为代码敲错了。

## 配置

行情源零配置就能跑。两个可选的 key 打开其余部分：

```json
{
  "sec_contact": "Your Name you@example.com",
  "fred_api_key": "",
  "output_language": "zh-CN",
  "sizing_method": "half_kelly",
  "position_cap": 1.0
}
```

- `sec_contact` —— SEC 要求 User-Agent 里带联系方式，不填会返回 403，美股财报就没有
  数据源。
- `fred_api_key` —— 圣路易斯联储免费申请，用来给折现率提供有出处的无风险利率。
- `output_language` —— 研报用什么语言写。填 `zh-CN` 出中文报告。程序自身的日志和
  报错保持英文，方便搜索排查。

任何时候跑一次 `status_report(configure())`，会列出哪些数据源现在能用、
缺的是哪一项设置。

## 常见问题

**它会告诉我买什么吗？**
不会。它呈现的是价格假设了什么、数据支持什么、什么情况下这个判断会被证伪。
每个阶段都停在给建议之前。

**它预测股价吗？**
不预测。反向 DCF 报出的是当前价格隐含的增速，这是对市场假设的一个描述。

**数据有多新？**
年度数据取自最近一份 10-K，季度数据取自已申报的季度，行情取最近一个正常交易时段
的收盘价。任何超过时效上限的数据会中断运行。

**能用在 A 股上吗？**
Wind 适配器按 Wind 官方文档的接口写成，但**没有在真实终端上验证过**——WindPy 随
付费产品分发，无法单独安装。请把它当作起点。

**我不同意它算出来的估值怎么办？**
你本来就应该能不同意。增长率和概率是你填的，折现率没有默认值、必须带来源提供，
交互式页面存在的意义就是让你把假设拖一拖，看答案怎么变。

**需要联网吗？**
取数需要。生成出来的估值页面之后可以离线打开。

## 已知边界

- 股东盈余 DCF 适合有稳定盈利、资本开支可辨认的生意。银行、保险、早期公司和很多
  REIT 都不适用，遇到这些它会说不适用，而不是硬给一个数字。
- 可保存的筛选 profile 设计已定、尚未实现，发现阶段目前跑的是通用搜索。
- Wind 适配器未经真实终端验证。
- 以上内容不构成投资建议。
